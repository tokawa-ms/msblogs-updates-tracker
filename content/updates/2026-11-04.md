#### [Arnis turns any place on Earth into a Minecraft world](https://github.blog/open-source/maintainers/arnis-turns-any-place-on-earth-into-a-minecraft-world/)
- 公開日時: 2026-11-03T16:00:00.000Z
- 要約: Arnisは、OpenStreetMapなどの実世界データをMinecraftの探索可能な世界に変換するオープンソースプロジェクトで、Louis Erbkammが2022年に始めた。GitHubからのダウンロードは約90万回に達し、約70人が貢献する一方、唯一のメンテナーであるErbkammはCopilotを使い、課題や不具合の把握、修正、回帰テストの検討を支援させている。近年は月や火星も対象に加わり、学校で地域の公園を題材にした授業にも使われている。
- なぜ重要か: Arnisは、地図データをMinecraftで探索したり、授業で地域の公園を共同で作り変えたりする手段を生徒や利用者に提供する。一方、再現できる要素は地図への登録状況に左右され、唯一のメンテナーにはプルリクエストが積み上がる。Copilotによる課題整理や回帰テストの支援は、メンテナーが定型作業を任せつつ開発に取り組むための使い方として紹介されている。

**重要ポイント**
- 選択した地域についてOpenStreetMapから地図上の要素を取得し、位置と種類に応じてMinecraft内に配置する。地図に登録されていない要素は配置できず、詳細な建造物には3Dモデルをブロックへ変換する方法も使う。
- プロジェクトはPythonで始まり、Rustへの移植前にはGitHub上で意見を募った。貢献者は約20言語への翻訳や独自機能の開発にも参加している。
- 単独メンテナーのErbkammはCopilotで課題や不具合の概要把握、原因追跡、修正を行い、大きなプルリクエストでは性能確認や回帰テストの観点出しにサブエージェントも使う。
- 学校では、同じ地域の生成ワールドを使い、生徒が公園や遊び場を改善して成果を比べる授業が行われている。
- 最近のリリースでは地球以外に月と火星が加わった。Erbkammは、使いやすさを保ちながら、より短時間で現実に近い詳細な世界を生成し、学校での利用も広げたいとしている。

<details><summary>English summary</summary>

Arnis is an open-source project that turns real-world data, including OpenStreetMap data, into explorable Minecraft worlds; Louis Erbkamm started it in 2022. It has reached close to 900,000 downloads from GitHub and about 70 contributors. As its sole maintainer, Erbkamm uses Copilot to help understand issues and bugs, make fixes, and consider regression tests. Recent releases added the Moon and Mars, and the project is also used in school lessons about local parks.

**Why it matters:** Arnis gives users and students a way to explore map data in Minecraft and collaboratively redesign local parks in lessons. At the same time, what can be represented depends on what is mapped, and pull requests accumulate for the sole maintainer. The article presents Copilot's help with issue triage and regression testing as a way for the maintainer to delegate routine work while focusing on development.

**Key points**
- For a selected area, Arnis retrieves mapped elements from OpenStreetMap and places them in Minecraft based on their location and type. Unmapped elements cannot be placed; 3D models can be converted into blocks for detailed structures.
- The project began in Python, and Louis sought input on GitHub before porting it to Rust. Contributors have also translated it into about 20 languages and built major features.
- As the sole maintainer, Erbkamm uses Copilot to review issues and bugs, trace causes, and make fixes. For large pull requests, he also uses sub-agents to review performance and suggest regression test cases.
- In schools, students have used the same generated area to improve a park or playground and compare their results.
- Recent releases added the Moon and Mars. Erbkamm wants to keep Arnis easy to use while making worlds more detailed and realistic in less time, and hopes to see it used in more schools.

</details>

### Microsoft 365 Blog (1)

#### [Announcing the new Work IQ APIs](https://www.microsoft.com/en-us/copilot/blog/2026/06/02/announcing-the-new-work-iq-apis/)
- 公開日時: 2026-06-02T17:00:15.000Z
- 要約: Work IQ APIsは、Microsoft 365のデータやアプリを業務上の文脈とともに扱い、組織内で動作するエージェントを構築するためのAPI群として発表された。GitHubでパブリックプレビューを利用でき、一般提供は2026年6月16日予定。Chat、Context、Tools、Workspacesの4領域を備え、Copilot Creditsによる従量課金と管理者向けコスト管理機能も示された。
- なぜ重要か: 開発者はMicrosoft 365の業務文脈を利用するエージェントを構築でき、IT管理者はテナント境界内でのデータ扱いや操作の監査性に加え、クレジット利用と支出上限を管理できる。これにより、エージェントの構築と運用管理に必要な機能を同じAPI群と管理体験で扱えることが記事の示す意義となる。

**重要ポイント**
- 現在、GitHubでパブリックプレビューを通じて構築を始められ、一般提供は2026年6月16日の予定。
- APIは4領域で構成される。ChatはCopilotの応答やエージェントへのプログラムアクセス、Contextはエージェント向けの文脈とソースデータ、ToolsはMicrosoft 365の操作、Workspacesはテナント内での作業中データや状態の保存を担う。
- ツール呼び出しをMCPによる10個の汎用ツールに集約し、開発者が多数のデータ別ツールをエージェントに教える必要を減らす設計。
- 料金はCopilot Credits建ての従量制で、Toolsには固定要素、ChatとContextには変動要素がある。Microsoft 365管理センターの新しいダッシュボードでは、クレジット利用状況の確認、前払いまたは従量払いの設定、支出上限の設定、利用者からのクレジット要求の監視が可能になる。
- データ、文脈、インサイトはMicrosoft 365のテナント信頼境界内にとどまり、エージェントの操作は監査・検出可能と説明されている。

<details><summary>English summary</summary>

Work IQ APIs were announced as a set of APIs for building agents that work with Microsoft 365 data and apps in business context. They are available now in public preview on GitHub, with general availability planned for June 16, 2026. The APIs span Chat, Context, Tools, and Workspaces, and include usage-based Copilot Credits pricing and cost-management features for admins.

**Why it matters:** Developers can build agents that use Microsoft 365 business context, while IT admins can manage credit usage and spending limits alongside data handling and auditability within the tenant boundary. The article presents the APIs and admin experience as bringing capabilities for building and operating agents together.

**Key points**
- Building can begin now through the public preview on GitHub; general availability is planned for June 16, 2026.
- The APIs comprise four domains: Chat provides programmatic access to Copilot responses and agents; Context provides agent-ready context and source data; Tools enables Microsoft 365 actions; and Workspaces stores in-progress data and state within the tenant.
- Tool calling is consolidated into 10 generic tools with progressive disclosure through MCP, reducing the need for developers to teach agents many data-specific tools.
- Pricing is usage-based in Copilot Credits, with a fixed component for Tools and variable components for Chat and Context. A new Microsoft 365 admin center dashboard will support usage review, prepaid or pay-as-you-go billing configuration, spending limits, and monitoring credit requests.
- The article says data, context, and insights remain within the Microsoft 365 tenant trust boundary, and agent actions are auditable and discoverable.

</details>
