#### [Announcing the retirement of R and Python visuals in Power BI](https://community.fabric.microsoft.com/t5/Power-BI-Updates-Blog/Announcing-the-retirement-of-R-and-Python-visuals-in-Power-BI/ba-p/5400748)
- 公開日時: 2026-11-09T19:00:39.000Z
- 要約: Power BIの組み込みR・Pythonビジュアルは2027年5月に廃止され、インタラクティブレポートでの利用が対象となります。Power BIサービス上の公開済みレポートでも廃止時に動作しなくなり、今後のPower BI Desktopでは追加できなくなりますが、Power Queryでテーブルを作成するPythonスクリプトは影響を受けません。
- なぜ重要か: R・Pythonビジュアルを含むレポートの所有者は、廃止後に公開レポートが動かなくなるため、対象の確認、置き換えの準備、利用者への周知が必要です。レポート利用者にも変更が及ぶため、置き換えをテストし、所有者でない利用者はレポート所有者に連絡するよう案内されています。

**重要ポイント**
- 廃止時には、Power BIサービス上の公開済みレポートにあるR・Pythonビジュアルは、廃止前に公開されたものも含めて動作しなくなります。一方、旧バージョンのDesktopでは、端末にインストールされたR・Pythonを使って引き続きローカル動作します。
- Rを使うカスタムビジュアルも廃止の影響を受けますが、Power Queryでテーブル作成に使うPythonスクリプトは対象外です。
- レポート内で元のR・Pythonビジュアルを完全に再現する移行方法はなく、廃止前に別の可視化へ置き換える必要があります。選択肢として、組み込み・既存カスタムビジュアルへの再構築や、Fabric notebooks、Fabric Appsでの再作成が示されています。
- PBIP形式とGit統合ワークスペースを利用している場合、ソース管理上のレポート定義を検索して対象ビジュアルを複数レポートから特定できます。PythonはpythonVisual、RはscriptVisualで検索します。

<details><summary>English summary</summary>

Power BI's built-in R and Python visuals will retire in May 2027, affecting their use in interactive reports. At retirement, they will stop working in published reports in the Power BI service, including reports published earlier, and future versions of Power BI Desktop will no longer let users add them. Python scripts used in Power Query to populate tables are not affected.

**Why it matters:** Owners of reports containing R or Python visuals need to identify affected reports, prepare replacements, and notify their organization because published reports will stop working after retirement. Report consumers are also affected, so the article says to test replacements and communicate changes in advance; users who do not own an affected report should contact its owner.

**Key points**
- At retirement, R and Python visuals in published reports in the Power BI service will stop working, including those published earlier. They will continue to work locally in older Desktop versions using R and Python installed on the machine.
- R-powered custom visuals are also affected, while Python scripts used in Power Query to populate tables are not.
- There is no in-report migration that recreates the exact R or Python visual, so it must be replaced before retirement. Options include rebuilding with built-in or existing custom visuals, or recreating the analysis in Fabric notebooks or Fabric Apps.
- Users of PBIP format and Git-integrated workspaces can search report definitions in source control to find affected visuals across reports, using pythonVisual for Python and scriptVisual for R.

</details>
