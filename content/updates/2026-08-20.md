#### [GitHub Copilot app for Beginners: Managing your work](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-managing-your-work/)
- 公開日時: 2026-08-19T17:50:23.000Z
- 要約: GitHub Copilot appのMy work paneでは、Copilot app内で触れたリポジトリに絞って、pull requestとissueをAll、Active、Review requests、Doneの各ビューでまとめて管理できる。独自ビューやフィルターも作成でき、担当作業やレビュー依頼、完了済み項目を同じ場所で追跡しながら、個別または複数のissueやpull requestから新しいCopilotセッションを始められる。
- なぜ重要か: 複数のCopilotセッションを並行して進め、PRやissueも同時に扱う開発者にとって、My work paneは進行中・完了・次の作業を1カ所で追える整理画面になる。さらに一覧の項目からそのままCopilotの新規セッションを起動できるため、課題の確認から作業着手までをアプリ内で続けやすい。

**重要ポイント**
- 標準ビューではAll、Active、Review requests、Doneが用意され、全件、オープン中、自分へのレビュー依頼、クローズ済みを切り替えて確認できる。
- 一覧の対象はGitHub全体ではなく、Copilot appで触れたプロジェクトに自動で絞られる。表示したいrepoがない場合は、そのrepoを指すセッションを作れば表示される。
- New viewから独自ビューを作成でき、GitHubで見慣れたangle-bracket syntaxかUIでフィルターを定義できる。例としてIs:IssueとAssignee:Meを保存すると、自分に割り当てられたissueだけのビューになる。
- 表示は既定のリスト viewに加えてtable viewへ切り替えられ、列の表示・並べ替え・幅調整を行える。必要なら元の状態へリセットしてリスト viewへ戻せる。
- 項目を開いてそのissueを文脈に新規セッションを始められ、複数項目を選んで新しいセッションも作成できる。複数のバグ報告を1つのセッションにまとめたり、issueのrepoとコードのrepoが別でもセッション側のrepoを切り替えたりできる。

<details><summary>English summary</summary>

The GitHub Copilot app's My work pane centralizes pull requests and issues for repositories you've touched in the app, with views for all, active, review-requested, and closed work. It also supports custom views and filters, and lets you start new Copilot sessions from one or multiple issues and pull requests.

</details>
