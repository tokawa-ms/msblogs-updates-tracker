#### [Your guide to GitHub Universe 2026 is here: The schedule just launched!](https://github.blog/news-insights/company-news/your-guide-to-github-universe-2026-is-here-the-schedule-just-launched/)
- 公開日時: 2026-08-13T19:00:00.000Z
- 要約: GitHub Universe 2026のセッションカタログが公開され、AI活用開発を軸にしたワークショップ、デモ、パネルの全体像が確認できるようになった。イベントは10月28日から29日にサンフランシスコのFort Mason Centerで開かれ、AMD、Figma、NVIDIA、Coinbase、Anthropic、OpenAIなどの登壇者が参加する。8月19日までの早期登録では300ドル割引があり、グループ割引と併用できる。
- なぜ重要か: GitHub CopilotやAI支援開発を実務に取り入れたい開発者やチームにとって、今回の公開は参加判断や学習計画を具体化しやすくする。手元のマシンで設定するハンズオンから、企業規模での測定、MCPサーバーの細粒度認可、GitHubチームとの個別対話まで含まれており、導入初期から大規模運用まで幅広い層に関係する。

**重要ポイント**
- 開催は10月28日〜29日の2日間で、会場は米サンフランシスコのFort Mason Center。AIを活用した開発の可能性を扱うセッション、デモ、パネルが並ぶ。
- 8月19日までに登録するとEarly Birdで300ドル安くなり、その後は価格が上がる。グループ割引との併用も可能。
- プログラムには、Copilotを複雑な作業に任せる設定、複数モデル対応のCopilot評価基盤、GitHub CLIを使ったstacked pull requests運用など、実務寄りの内容が含まれる。
- 8月21日までに投票すると、3つの候補セッションのうち1本がメインステージに進む。勝ったセッションはオンデマンドでも視聴可能で、登録時には50ドルのDay of Learning追加パスや30ドルの認定試験バウチャーも選べる。

<details><summary>English summary</summary>

The GitHub Universe 2026 session catalog is now live, outlining workshops, demos, and panels centered on AI-powered development. The event runs October 28-29 at Fort Mason Center in San Francisco, with speakers from GitHub and companies including AMD, Figma, NVIDIA, Coinbase, Anthropic, and OpenAI. Early Bird registration before August 19 saves $300 and can be combined with group discounts.

</details>

#### [What 50 open source projects taught us about security in the AI era](https://github.blog/open-source/maintainers/what-50-open-source-projects-taught-us-about-security-in-the-ai-era/)
- 公開日時: 2026-08-13T16:00:00.000Z
- 要約: GitHub Secure Open Source FundのSession 4では、50件のオープンソースプロジェクトに総額50万ドル超を投じ、GitHub Security Labの専門家、GitHubのセキュリティツール、AI支援ワークフローを組み合わせる支援へ拡充した。参加メンテナーはこの支援を具体的なセキュリティ改善に結び付け、AIは調査・優先順位付け・対応の高速化に有効だが、最終判断と責任はメンテナーが担うという教訓が示された。
- なぜ重要か: 影響を受けるのは、AIやクラウド、開発基盤を支えるオープンソースのメンテナーと、それらに依存する開発者や組織だ。記事は、メンテナーが脆弱性管理やリリース保護を続けながらAI由来の新しいリスクにも対処する必要があり、その改善が下流の多数のアプリケーションと依存先全体の強靱性向上につながると位置付けている。

**重要ポイント**
- Session 4は50プロジェクトに50万ドル超を投資し、GitHub Security Labの専門家、GitHubセキュリティツール、AI支援ワークフロー、ピアコミュニティを組み合わせて支援した。
- 各セッションは3週間のスプリントと計12カ月の関与で構成され、資金提供と参加は成果主導の目標および検証済みのセキュリティ改善に直接結び付けられている。
- 各プロジェクトにはGitHub Sponsors経由で1万ドルが支給され、内訳はスプリント中6000ドル、6カ月後と12カ月後のセキュリティ確認時に各2000ドルで、即時導入向けのセキュリティ資源とAzureクレジットも提供される。
- OpenClawはSession 4の終了時までに、インシデント対応計画の策定、GitHubセキュリティツール利用の拡大、GitHub Actionsワークフローの監査、セキュリティ問題の特定と対応プロセスの強化を実施した。
- 次回のSession 5は8月24日まで応募を受け付けており、Funding PartnerまたはEcosystem Partnerとしての参加募集も案内している。

<details><summary>English summary</summary>

In Session 4, the GitHub Secure Open Source Fund expanded support for 50 open source projects with more than $500,000, combining GitHub Security Lab expertise, GitHub security tools, and AI-assisted workflows. Maintainers turned that support into concrete security improvements, while the program’s main lesson was that AI can speed investigation, prioritization, and response, but maintainers still make the final decisions and remain accountable.

</details>
