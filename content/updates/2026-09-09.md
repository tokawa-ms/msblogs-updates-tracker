#### [GPT-6 Astra: Frontier intelligence for work, now available in Microsoft Foundry](https://azure.microsoft.com/en-us/blog/gpt-6-astra-frontier-intelligence-for-work-now-available-in-microsoft-foundry/)
- 公開日時: 2026-09-03T18:15:00.000Z
- 要約: GPT-6 Astra が Microsoft Foundry の全顧客向けに一般提供された。記事が強調するのは、質問への回答だけでなく、作業を計画し、文書・分析資料を作成し、複数アプリを操作して業務を進める能力だ。専用 API のない画面も操作対象になる一方、重要な処理には人の承認やアクセス制限が必要となる。提供方式は Standard と Provisioned Throughput で、Global と US Data Zone に対応する。（2026年9月10日確認の原文に基づく。）
- なぜ重要か: 専用 API がない業務アプリも、承認済みの画面操作を通じて一連の作業に組み込める点が重要。複数アプリをまたぐ処理を検討する企業にとって、モデルの能力だけでなく、操作権限・人の承認・監視を含めた実行環境の設計が導入上の論点になる。

**重要ポイント**
- 業務実行: 不具合の再現・修正案の作成、Power BI ダッシュボードの改善、テンプレートに沿った文書作成、顧客レコードの更新などを想定。成果物は開発者や専門家によるレビューが前提となる。
- 安全策: 画面内の情報がエージェントを誤誘導する可能性を指摘。権限を絞った認証情報、承認済みリソース、重要操作での人の確認、操作記録を組み合わせる。Foundry の安全機能だけでリスクがなくなるわけではない。
- 提供と課金: Standard は従量課金、Provisioned Throughput は専用のモデル処理容量。Global と US Data Zone の両方で選択できる。
- 価格の違い: 記事記載の Standard Global は100万トークン当たり、短文脈で入力10米ドル・出力50米ドル、長文脈で入力20米ドル・出力75米ドル。US Data Zone は別単価で、文脈長や構成により費用が変わる。
- 性能の読み方: computer use の最先端評価結果は OpenAI の報告として紹介されている。実際の性能はタスク、ツール、構成、安全策に依存し、あらゆる業務で同じ成果が得られるとは述べていない。

<details><summary>English summary</summary>

GPT-6 Astra is generally available to all Microsoft Foundry customers, according to the article checked on September 10, 2026. It focuses on planning work, producing documents and analyses, and operating across applications, including interfaces without dedicated APIs. Consequential actions require human oversight and scoped access. Standard and Provisioned Throughput deployments are offered in Global and US Data Zone geographies.

</details>
