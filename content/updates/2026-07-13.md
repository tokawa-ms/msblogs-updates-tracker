### Azure Blog (1)

#### [Frontier models and production agents: Advancing Microsoft Foundry for the agentic era](https://azure.microsoft.com/en-us/blog/frontier-models-and-production-agents-advancing-microsoft-foundry-for-the-agentic-era/)
- 公開日時: 2026-07-09T17:00:00.000Z
- 要約: Microsoft Foundryは、GPT-5.6シリーズ、APAC向けのAsia-Pacific Data Zone、Foundry Agent Serviceの本番向け機能を一般提供し、AIエージェントを単一基盤で構築・運用・配布できるようにした。Foundry Agent Serviceではhosted agentsやToolboxesなどの本番機能がGAとなり、Microsoft 365向けの配布経路も用意される。これにより企業は、モデル選択から実行基盤、統制、配布までを分断された複数製品にまたがらず扱える。
- なぜ重要か: 恩恵を受けるのは、既存の開発環境からそのまま本番エージェントを展開したい企業開発チームと、APACで地域内処理や統制を重視する組織だ。Foundryがモデル、実行基盤、観測・評価、Microsoft 365への配布までをまとめることで、分断されたツールを個別に組み合わせずに、実験段階から大規模運用へ移しやすくなる。

**重要ポイント**
- Microsoft Foundry ModelsとFoundry Agent ServiceでGPT-5.6シリーズをGA。Solは高度な推論やコード重視シナリオ向け、TerraはGPT-5.5並みの性能をより低コストで狙う日常用途向け、Lunaは高速・低価格で高ボリュームかつ低遅延の用途向けに位置付けられている。
- 最新GPT-5.6は既存28のグローバルリージョン向けに、Global Standard、Global Priority Processing、Data Zones Standard、Global Provisionedで初日から提供される。Standard Globalの価格は100万トークン当たり、Solが入力5.00ドル・出力30.00ドル、Terraが入力2.00ドル・出力12.00ドル、Lunaが入力0.20ドル・出力1.20ドルで、SolのAzure OpenAIメータードAPIは2026年9月1日から少なくとも11月30日まで入力4.00ドル・出力20.00ドルの販促価格になる。
- Asia-Pacific Data ZoneがGAとなり、APACの顧客はデータ処理をアジア太平洋域内に維持したままfrontier OpenAI modelsを実行できる。FoundryはGlobal、Data Zone、Regionalの展開オプションをそろえ、主権・コンプライアンス・性能要件に合わせた配置を選べる。
- Foundry Agent Serviceではhosted agents、Voice Live対応のhosted agents、ToolboxesがGA。さらにMicrosoft TeamsとMicrosoft 365 Copilotへの公開は翌週からGAとなり、構築したエージェントを業務アプリに届けやすくする。
- 運用面では、Memory and routinesはpublic preview、hosted agents向けtracing and evaluationはGA、agent optimizerはpublic preview、ROI for agentsはprivate previewとして提供される。エージェントの状態保持、挙動の可視化、構成最適化、価値とコストの把握を段階的に追加している。

<details><summary>English summary</summary>

Microsoft Foundry has generally released the GPT-5.6 series, the APAC Asia-Pacific Data Zone, and production capabilities in Foundry Agent Service, making it a single platform for building, running, governing, and distributing AI agents. Hosted agents and toolboxes are now GA, and the platform is positioned to cover model choice, runtime, controls, and distribution without requiring separate disconnected services.
