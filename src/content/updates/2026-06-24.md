- Summary: GitHub has joined an open source coalition of Black Forest Labs, Hugging Face, and Mozilla Corporation calling for targeted amendments to California’s AI Transparency Act (SB 942, as proposed to be amended in SB 1000). Read the full letter here. At issue is a narrow but important problem for developers: as currently drafted, the bill’s license revocation provisions conflict with how open source licenses work in practice. Open source licenses are designed to be perpetual and irrevocable, which is what allows developers to reliably build on, reuse, and share code across projects and organizations. The proposed language would require developers to revoke licenses if downstream users fail to meet certain obligations.
