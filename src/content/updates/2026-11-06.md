The new Power Query experience (Preview) in Power BI Desktop organizes Get data into modules for users who know their source, want to find existing OneLake items or recent data, or need to create values or queries. **Why it matters:** Users can choose an entry point suited not only to those who know a source name or location, but also to those looking for team-maintained data in context or starting from existing values or queries. Authentication and access permissions are still required, and limitations remain for users who depend on editing SQL settings, advanced Web connections, or combining files.

**Key points**
- Desktop offers New, Recent data, OneLake catalog, Blank table, and Blank query, with entry points suited to known sources, existing data, or starting from values or M queries.
- Modules and actions vary by host. Browse Azure, SharePoint browsing, and Upload are not currently Desktop modules; they are available in Dataflow Gen2 and other supported hosts. There is no committed Desktop release date.
- Native SQL input when creating a connection has been restored for supported connectors, but reopening settings from the Source step is still only partially supported. Work also continues on restoring advanced Web API and Web Page settings and addressing Combine Files issues.
