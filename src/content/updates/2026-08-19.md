### Azure Blog (1)

#### [Microsoft named a Leader in the 2026 Gartner® Magic Quadrant™ for Cloud-Native Application Platforms](https://azure.microsoft.com/en-us/blog/microsoft-named-a-leader-in-the-2026-gartner-magic-quadrant-for-cloud-native-application-platforms/)
- 公開日時: 2026-08-17T15:00:00.000Z
- 要約: MicrosoftのAzureクラウドネイティブアプリケーション基盤は、2026年のGartnerのCloud-Native Application Platforms Magic Quadrantで3年連続のLeaderに位置付けられたと同社が発表した。記事では、Azure App Service、Container Apps、Functions、API ManagementをMicrosoft FoundryやGitHub Copilotと組み合わせ、AIアプリやエージェントの本番運用、既存アプリのモダナイズ、運用とガバナンスを単一基盤で支える構成を打ち出している。
- なぜ重要か: 既存アプリ資産を残したままAI活用を進めたい企業や、セキュリティとガバナンスを維持しつつAIアプリを本番展開したい運用チームに関係する内容だ。記事は、Windows/.NETを含む既存アプリのモダナイズと新しいAIワークロードの運用を同じAzure基盤で扱えると位置付けており、別々の基盤や運用モデルを増やさず進めたい組織に影響する。

**重要ポイント**
- Microsoftは2026年版Gartner Magic Quadrant for Cloud-Native Application PlatformsでLeaderとされ、同社によればこれで3年連続となる。
- AIアプリとエージェント向けには、Azure Container Apps Expressでコンテナを直接本番エンドポイントへ配備でき、Azure Functionsで既存ロジックをModel Context Protocol経由で公開できる。さらに1,400超のコネクタで企業システム連携を支援する。
- 運用とセキュリティでは、Azure API ManagementのAI gateway機能が認証、トークン制限、クオータ、モデル間のトラフィック分散、semantic caching、利用監視を担い、Azure Container Apps Sandboxesがエージェント生成コードや非信頼コードの隔離実行を支える。
- 顧客事例として、Planet DDSはAzure App Serviceへのモダナイズでプロビジョニング時間を6週間から1日に短縮した。CommerzbankのAvaはAzure Container Apps上で月3万件超の顧客会話を処理し、その75%を自律的に解決している。

<details><summary>English summary</summary>

Microsoft says its Azure cloud-native application platform was named a Leader in Gartner’s 2026 Magic Quadrant for Cloud-Native Application Platforms for the third consecutive year. The article presents Azure App Service, Container Apps, Functions, and API Management, together with Microsoft Foundry and GitHub Copilot, as a single platform for running AI apps and agents in production, modernizing existing applications, and providing governance and operations.

</details>

### Microsoft Fabric Blog (1)

#### [Power BI June 2026 Feature Summary](https://community.fabric.microsoft.com/t5/Power-BI-Updates-Blog/Power-BI-June-2026-Feature-Summary/ba-p/5193264)
- 公開日時: 2026-07-31T15:26:07.000Z
- 要約: Power BIの2026年6月更新では、AI支援、モデリング、レポート作成まわりの機能がまとめて拡張された。今回の更新は一般提供とプレビューが混在しており、Copilot in web modelingは今月Power BI serviceでロールアウトされ、DAX user-defined functionsは一般提供となった。あわせて、いったん停止していたPBIR既定化の方針は維持され、6月にservice、7〜8月にDesktopへ再開する計画も示された。
- なぜ重要か: 恩恵を受けるのは、レポート作成者とPower BIデータを日常業務で使う業務ユーザーだ。作成者は手動編集や定期的な日付スライサー更新の負担を減らせ、データ回答機能は既存の権限とセマンティックモデルに基づいて答えを返すため、利用者はM365 Copilot内でレポートと整合した情報にアクセスしやすくなる。

**重要ポイント**
- Copilot in web modelingはプレビューで今月Power BI serviceに展開され、自然言語でセマンティックモデルの分析・改善に加え、テーブル名や列名の変更、リレーション作成、DAXメジャー生成まで行える。
- スライサー向けDate pickerはプレビューとして追加され、相対日付の既定値を公開後もデータ更新に合わせて自動で進められる。利用には Options &gt; Preview features で有効化する必要がある。
- DAX user-defined functionsは一般提供となり、計算をメジャー、計算列、ビジュアル計算で再利用できる。さらにSSMSは22.5以降でUDFの作成・更新をサポートする。
- PBIRの既定オン展開は問題対応のため一時停止していたが、既定フォーマット化の方針自体は変わっていない。6月にPower BI serviceで再開し、順調なら7〜8月にDesktop、PBIR/PBIPのGAはその後となる見込みだ。

<details><summary>English summary</summary>

Power BI’s June 2026 update expands AI assistance, modeling, and report authoring features. It mixes preview and GA releases: Copilot in web modeling is rolling out this month in the Power BI service, DAX user-defined functions are now generally available, and the paused PBIR default rollout is set to resume in the service in June and in Desktop in July/August.

</details>
