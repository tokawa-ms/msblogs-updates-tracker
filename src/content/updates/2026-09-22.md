### Azure Blog (1)

#### [Introducing Azure Multicloud Interconnect for AWS](https://azure.microsoft.com/en-us/blog/introducing-azure-multicloud-interconnect-for-aws/)
- 公開日時: 2026-08-31T18:00:00.000Z
- 要約: Azure Multicloud Interconnectは、AWS Interconnect – multicloudと連携してAzureとAWS間の専用プライベート接続を簡素化する新しいマルチクラウド接続ソリューションとして発表された。ネットワーク相互運用のOpen API仕様に基づく統合プロビジョニングにより、従来は個別調整が必要だった接続構築や運用の複雑さを減らす。Azure Private Linkまで含むエンドツーエンドのプライベートパスを提供する設計で、一般提供時には初日から最大100Gbpsに対応するとしている。
- なぜ重要か: AzureとAWSをまたいでAI、データ移動、ミッションクリティカルなワークロードを運用する組織にとって重要な発表だ。これまで数週間から数か月かかり得たプライベート接続の構築、調整、監視、ライフサイクル管理の負担を減らしつつ、性能・セキュリティ・コンプライアンス要件を維持したマルチクラウド構成を取りやすくするためである。

**重要ポイント**
- AzureとAWSは、ネットワーク相互運用のOpen API仕様に基づいて協業し、両クラウド間の専用プライベート接続を統合されたクラウドネイティブ体験でプロビジョニングできるようにする。
- AIの学習・推論で分散したデータやアプリケーションを扱う需要を想定し、Azure Private Linkまで延びるエンドツーエンドのプライベート経路を提供する設計になっている。
- 一般提供時には初日から最大100Gbpsの接続速度に対応し、需要増加に応じて容量を動的に拡張でき、運用を止めたりネットワーク構成を作り直したりせずにスケールできるとしている。
- 記事では、従来の接続方法の煩雑さに対する改善点として、MACsecを標準で備え、99.99%可用性とクリック操作でのスケーリングを実現すると述べている。

<details><summary>English summary</summary>

Azure Multicloud Interconnect was introduced as a new multicloud connectivity solution that works with AWS Interconnect – multicloud to simplify dedicated private connectivity between Azure and AWS. It uses integrated provisioning based on Open API specifications for network interoperability to reduce the complexity of building and operating connections that previously required separate coordination. It is designed to provide an end-to-end private path extending to Azure Private Link, and Microsoft says it will support up to 100 Gbps from day one at general availability.

**Why it matters:** This matters for organizations running AI, data movement, and mission-critical workloads across both Azure and AWS. It is intended to reduce the burden of building, coordinating, monitoring, and managing private connectivity that could previously take weeks or months, while making it easier to keep performance, security, and compliance requirements in a multicloud architecture.

**Key points**
- Azure and AWS are collaborating based on Open API specifications for network interoperability so customers can provision dedicated private connectivity between the two clouds through an integrated cloud-native experience.
- The offering is designed for AI training and inference scenarios involving distributed data and applications, with an end-to-end private path that extends to Azure Private Link.
- At general availability, it is slated to support connectivity speeds of up to 100 Gbps from day one, with dynamic capacity expansion so organizations can scale without disruption or network redesign.
- The article says the service improves on older, clunky connection methods with MACsec security out of the box, 99.99% availability, and click-button scalability.

</details>
