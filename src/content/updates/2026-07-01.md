- 公開日時: 2026-06-29T17:00:00.000Z

- AIやデータ集約型ワークロード向けには、新しいZonal placementでGPU仮想マシンと同じ可用性ゾーンにファイル共有を配置でき、provisioned v2 billing modelでIOPSとスループットを独立して設定できる。
- クラウドネイティブ領域では、Azure Files CSI driverを通じてAKSと統合し、StorageClassesによる動的プロビジョニング、拡張可能な永続ボリューム、ReadWriteManyの共有アクセスを提供する。さらに新しいfile share experienceは、1サブスクリプション・1リージョン当たり最大10,000共有と約2.5倍高速なプロビジョニングをうたう。

- パートナーやISV向けには、独自APIではなくSMB 3.xとNFS 4.1の標準プロトコルを前面に出し、NFS Snapshot、Soft Delete、NFS shares向けREST APIを通じてBCDR、データ移動、管理、アプリ連携を組み込みやすくした。

- 要約: GitHub License Complianceは、GitHubのOSPOが内部専用ツールから移行し、数千件のオープンソース依存関係をプルリクエスト上で審査するために使っている新機能だ。GitHubはまず組織全体のrulesetで「Evaluate」モードを約1か月運用し、マージを止めずに開発者を慣らしたうえで、異常・欠落・明示的に禁止されたライセンスの検出を絞り込んだ。機能は現在public previewで、activeなGHAS Code Securityライセンスを持つGitHub Enterprise Cloudのリポジトリで利用できる。
- なぜ重要か: 大規模にオープンソース依存関係を扱う企業の開発者やライセンスポリシー担当者にとって、依存関係追加時点のPRレビューでライセンス適合性を確認し、例外申請も一元管理できる点が重要だ。記事では、後から不適切なライセンスを除去するには追加のエンジニアリング作業が必要になり得て、法務・運用上のリスクも大きいため、複雑な要件を持つ企業ほど早期検知の恩恵を受けると説明している。

- 対象リポジトリでは、依存関係を変更するPRで直接・推移依存のライセンスをスキャンし、問題があればPRにアラートを投稿する。開発者は依存関係を外すか、例外申請を出してポリシー改定を依頼できる。

- 緊急時はcustom propertyの値を切り替えてルール適用を一時停止できる「break glass」運用を用意しており、これまで1回だけ使った。現在はpublic previewで、利用対象はactiveなGHAS Code Securityライセンスを持つGitHub Enterprise Cloudのリポジトリだ。

#### [Power BI Desktop Bridge (Preview)](https://community.fabric.microsoft.com/t5/Power-BI-Updates-Blog/Power-BI-Desktop-Bridge-Preview/ba-p/5227769)
- 公開日時: 2026-06-30T19:00:00.000Z
- 要約: Power BI Desktop Bridgeでは、外部アプリやエージェントがPower BI Desktopと直接やり取りできるようになり、レポート状態の取得、ファイル再読み込み、スクリーンショット取得をローカル経由で行えるようになった。これにより、ディスク上のレポート編集後にDesktopへ即時反映し、見た目の確認まで含めた反復作業を手作業なしで進めやすくなる。加えてBridge CLIが用意され、manifest、status、reload、screenshot-allなどのコマンドから機能を利用できる。
- なぜ重要か: Power BI Desktopを外部ツールやエージェントと組み合わせたい利用者、特にPBIR/PBIPをディスク上で編集しながら確認するワークフローに関わる人に影響がある。Bridgeにより、現在状態の把握、変更の再読み込み、スクリーンショットでの検証までを同じ流れで実行でき、従来はDesktopと直接対話できずに生じていた手戻りや手動引き継ぎを減らせる。

**重要ポイント**
- Bridgeはローカルの軽量サーバーとして動作し、外部アプリやエージェントがPower BI Desktopの機能一覧取得、現在のファイル状態確認、レポートのPNGスクリーンショット取得、PBIP/PBIRファイルの再読み込みを直接実行できる。

- Desktop Bridgeは既定で有効化されており、Power BI Desktopの File &gt; Options and settings &gt; Options &gt; Preview features から secure local APIs 経由の外部ツールアクセス設定を有効・無効にできる。
- Power BI Desktop Bridge CLIでは、manifest、status、reload、screenshot-allの各コマンドが提供され、特にreloadはDesktopを閉じたり開き直したりせずにPBIRのディスク変更を反映できる。

<details><summary>English summary</summary>

Power BI Desktop Bridge adds a lightweight local server that lets external apps and agents interact directly with Power BI Desktop, including reading report state, reloading edited files, and capturing screenshots.
