#### [Responsible infrastructure at hyperscale: Managing the full lifecycle of Azure hardware](https://azure.microsoft.com/en-us/blog/responsible-infrastructure-at-hyperscale-managing-the-full-lifecycle-of-azure-hardware/)
- 公開日時: 2026-09-30T15:00:00.000Z
- 要約: Microsoft Azureは、退役ハードウェアを扱うMicrosoft Circular Centersをウェールズのニューポートとオーストラリアのシドニーに新設し、北米・欧州・アジア太平洋をまたぐ運用体制を拡大した。あわせてAzure基盤では、2014年以降ラック当たりのコア数が約13倍に増え、同じ処理に必要な電力は約90%減少したと説明している。さらに同社は、昨年の退役サーバーと部品で92%の再利用・再資源化率を達成し、新旧ハードウェアのライフサイクル全体を最適化していると述べた。
- なぜ重要か: Azure利用者にとって重要なのは、同じデータセンターの設置面積と電力でより多くのサーバー能力を提供できるようになる点と、旧機材の回収・再利用で新しいインフラ向けのスペース確保や部材寿命の延長が進む点だ。これにより、基盤更新と資源活用を並行して進めながら、顧客ワークロードを支える能力を増やせるというのが同社の説明である。

**重要ポイント**
- Microsoft Circular Centersはウェールズとオーストラリアで最近稼働し、現在は北米・欧州・アジア太平洋で8拠点となった。さらに米テキサス州サンアントニオの新拠点も計画されている。
- Azure基盤の高密度化が進み、2014年比でラック当たりコア数は約13倍になり、コードコンパイルのような処理の消費電力は約100ワットから10ワット未満に下がったという。
- Azure Cobalt 200は、Cobalt 100比で最大50%高い性能をうたい、最新のMicrosoftのセキュリティ、ネットワーク、ストレージ技術を組み込む。
- 昨年の退役サーバーと部品の再利用・再資源化率は92%で、完全なシステムは社内ラボや研修、学校・大学、適格な買い手向けに回され、再利用できない場合に資材が再資源化される。

<details><summary>English summary</summary>

Microsoft Azure expanded its Microsoft Circular Centers for retired hardware with new sites in Newport, Wales, and Sydney, Australia, extending operations across North America, Europe, and Asia Pacific. It also says Azure infrastructure has improved sharply since 2014, with roughly 13 times more cores per rack and about 90% less power needed for the same task. Microsoft added that it achieved a 92% reuse and recycling rate for decommissioned servers and components last year, aiming to optimize the full hardware lifecycle.

**Why it matters:** For Azure customers, the key point is that Microsoft says it can deliver more server capacity within the same datacenter space and power envelope, while recovering and reusing older hardware helps free space for new infrastructure and extend component life. In Microsoft’s framing, that lets it expand the capacity supporting customer workloads while updating infrastructure and making further use of existing resources.

**Key points**
- Microsoft Circular Centers recently launched in Wales and Australia, bringing the network to eight sites across North America, Europe, and Asia Pacific. A new site is also planned for San Antonio, Texas.
- Azure infrastructure has become denser and more efficient: cores per rack are up about 13-fold versus 2014, and a workload such as code compilation dropped from about 100 watts to under 10 watts.
- Azure Cobalt 200 is claimed to deliver up to 50% higher performance than Cobalt 100 and includes Microsoft’s latest security, networking, and storage technologies.
- Last year, the reuse and recycling rate for decommissioned servers and components reached 92%; complete systems can be redirected to internal labs and training, schools and universities, or qualified buyers, while materials are recycled when reuse is no longer possible.

</details>

#### [SQL Server on Azure Local is now generally available](https://www.microsoft.com/en-us/sql-server/blog/2026/09/28/sql-server-on-azure-local-is-now-generally-available/)
- 公開日時: 2026-09-29T16:40:06.000Z
- 要約: SQL Server on Azure Localが一般提供となり、接続環境と切断環境の両方でSQL ServerをAzure Local上に展開できるようになった。自社データセンターやエッジ拠点で、インフラ、接続性、データ配置の制御を保ちながら運用できる。加えて既存のSQL Serverライセンスを活用でき、AI推論向けのFoundry Local on Azure Localは2026年9月29日時点でプレビュー提供とされている。
- なぜ重要か: 主に恩恵を受けるのは、主権、規制、低遅延、運用継続性、エッジ要件のためにローカル制御が必要な組織や、接続制約のある環境を持つ業種だ。公共部門、防衛、金融、医療、製造、エネルギーなどは、外部接続が前提でない場所でもSQL ServerをAzure整合の基盤で運用し、必要に応じてローカルAI機能も取り込める。

**重要ポイント**
- 展開形態は2種類あり、接続環境ではAzure Arc経由でAzureからSQL Serverリソースを管理できる一方、ALDOでは外部接続が制限・断続的・不在でもローカルで運用を継続できる。
- 対象基盤は顧客のデータセンターやエッジ拠点にあるAzure Localで、Windows ServerまたはLinuxを実行する仮想マシン上のSQL Serverワークロードをサポートする。
- ライセンスはSQL ServerとAzure Local基盤が別体系で、接続構成ではSoftware Assurance付きライセンスや対象サブスクリプションを含む既存ライセンス、またはAzure Arc経由の従量課金を使える。完全切断構成ではAzure Hybrid Benefit経由で対象の既存ライセンスを利用する。
- Foundry Local on Azure Localでは、SQL Serverと並べてAzure Local上でAIモデルを動かし、データの近くで推論できる。ただしFoundry Local on Azure Localは2026年9月29日時点でプレビューであり、提供状況や機能は一般提供前に変わりうる。

<details><summary>English summary</summary>

SQL Server on Azure Local is now generally available, enabling SQL Server deployments on Azure Local in both connected and disconnected environments. Organizations can run it in their own datacenters and edge sites while retaining control over infrastructure, connectivity, and data placement. It also supports use of existing SQL Server licenses, while Foundry Local on Azure Local for AI inference is in preview as of September 29, 2026.

**Why it matters:** The main beneficiaries are organizations that need local control for sovereignty, regulatory, low-latency, operational continuity, or edge requirements, as well as industries with connectivity-constrained environments. Public sector, defense, financial services, healthcare, manufacturing, and energy organizations can run SQL Server on Azure-consistent infrastructure even where external connectivity cannot be assumed, and can incorporate local AI capabilities when needed.

**Key points**
- There are two deployment models: connected environments can manage SQL Server resources through Azure via Azure Arc, while ALDO supports continued local operations when external connectivity is restricted, intermittent, or unavailable.
- The platform targets Azure Local in customer datacenters and edge locations, and supports SQL Server workloads on virtual machines running Windows Server or Linux.
- Licensing for SQL Server is separate from the Azure Local infrastructure platform. Connected deployments can use eligible existing licenses, including Software Assurance licenses or qualifying subscriptions, or pay-as-you-go through Azure Arc. Fully disconnected deployments use eligible existing licenses through Azure Hybrid Benefit.
- Foundry Local on Azure Local lets customers run AI models alongside SQL Server on Azure Local and perform inference close to the data. However, Foundry Local on Azure Local is in preview as of September 29, 2026, and its availability and capabilities may change before general availability.

</details>
