### Azure Blog (1)

#### [From insight to action: The next phase of agentic cloud operations](https://azure.microsoft.com/en-us/blog/from-insight-to-action-the-next-phase-of-agentic-cloud-operations/)
- 公開日時: 2026-06-23T15:45:00.000Z
- 要約: Azure Copilot observability agentが一般提供となり、Azureでは環境全体のテレメトリーを継続分析して、障害の兆候把握から調査支援までを日常運用に取り込めるようになった。あわせてAzure Resource Manager MCP Serverがパブリックプレビューとなり、コストと使用量のデータをAIエージェントや開発ツールへ標準的に接続できるようにしている。記事は、観測、ガバナンス、最適化を人間が関与するポリシー付きの閉ループ運用として結び付ける構想を示している。
- なぜ重要か: ハイブリッド基盤、マイクロサービス、AIワークロードを運用する開発者、IT、運用チームに関わる内容で、手作業では追い切れなくなったテレメトリーやアラート、変動しやすいコスト利用を、ポリシーとアクセス制御付きのエージェントで扱えるようにする点が重要だ。とくに、開発者はコスト影響を意識しながら構築でき、運用チームは自然言語で調査と最適化を進められるため、障害対応と最適化が同じ運用ループに統合される。

**重要ポイント**
- Azure Copilot observability agentは、アプリケーショントポロジー、依存関係、ベースライン挙動を含む環境全体のテレメトリーを継続分析し、問題の兆候が出た段階でパターン検出と調査開始を支援する。
- インシデント対応では、関連シグナルの自動グルーピングやサービス間依存関係の追跡によりノイズ削減と根本原因の絞り込みを進め、判断に必要な文脈付き提案を提供するとしている。
- 導入効果の例として記事は、観測エージェントによりインシデント解決の高速化と運用負荷の削減が進み、月あたり推定250時間のエンジニアリング時間を取り戻したという利用者の声を紹介している。
- 最適化では、Microsoftはコスト、性能、レジリエンス、サステナビリティを継続改善する実践と定義し、AIによる変動の大きい利用パターンのため、定期レビュー中心の従来型コスト管理だけでは対応しにくいと説明している。
- Azure Resource Manager MCP Serverのパブリックプレビューでは、AIエージェントが標準化インターフェース経由でコスト・使用量データへアクセスでき、カスタム統合なしで開発環境、copilot、独自ワークフローにその知見を持ち込める。

<details><summary>English summary</summary>

Azure Copilot observability agent is now generally available, bringing continuous telemetry analysis and assisted investigation into day-to-day Azure operations. Microsoft is also putting the Azure Resource Manager MCP Server into public preview so cost and usage data can flow into AI agents and developer tools. Together, the article frames observability, governance, and optimization as a human-governed closed-loop operating model.

</details>
