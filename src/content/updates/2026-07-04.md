#### [Claude in Microsoft Foundry is now generally available](https://azure.microsoft.com/en-us/blog/claude-in-microsoft-foundry-is-now-generally-available/)
- 公開日時: 2026-06-29T17:00:00.000Z
- 要約: Microsoft FoundryのClaudeが一般提供となり、Azure上で既存のAzureアカウントを使って本番導入できるようになった。開発者はMessages API経由でprompt caching、extended thinking、tool streamingを利用でき、Foundry Agent ServiceではClaudeを中核に複数ステップの計画やツール実行を行うエージェントを構成できる。推論はAzureで処理され、GlobalとUSのデータゾーン、ゼロデータ保持、Azureの認証・課金・ガバナンス統合も提供される。
- なぜ重要か: Azureを標準基盤として使う企業や、データ所在地・統制・高機密要件を持つチームにとって影響が大きい。記事では、本番移行の障害はモデル品質よりも調達、ガバナンス、ネットワーク、データ管理にあるとし、既存のAzure認証・課金・統制を使ったままClaudeを導入できることで、エージェント実験から本番運用への移行を進めやすくすると位置づけている。

**重要ポイント**

- 課金はClaude Consumption Units（CCU）としてAzure請求書の単一明細に集約され、MACC drawdownに対応しつつFoundry側のモデル別詳細は維持される。加えて、model routerは最適なClaudeモデルへ自動振り分けし、最大50%の節約とうたっている。

#### [Accelerate modern Linux workloads with Azure Files](https://azure.microsoft.com/en-us/blog/accelerate-modern-linux-workloads-with-azure-files/)
- 公開日時: 2026-06-29T15:00:00.000Z
- 要約: Azure Filesは、Linux向けのフルマネージドファイルストレージとして、NFSベースのモダンLinuxワークロード向け機能を拡充した。AI推論では新しいZonal placementとprovisioned v2 billing modelにより、GPU VMと同一ゾーン配置やIOPS・スループットの個別調整を可能にする。AKS向けにはCSI driver連携に加え、新しいfile share experienceで1サブスクリプション・1リージョン当たり最大10,000共有と約2.5倍高速なプロビジョニングをうたい、既存NFSアプリ向けにAzure Storage MoverとAzure Migrate support for NFSも打ち出した。
- なぜ重要か: 恩恵を受けるのは、GPUを使うAI推論基盤、AKSでRWX共有ストレージを必要とするクラウドネイティブ運用、既存のLinux/NFS業務アプリをAzureへ移す企業、そしてSMB 3.xやNFS 4.1前提で統合するISVやパートナーだ。Azure Filesが標準プロトコルと移行・保護機能をまとめて提供することで、既存アプリを大きく変えずに共有ストレージをAzureへ集約しやすくなる。

**重要ポイント**
- AI推論では、モデル重みを各レプリカが個別に持つのではなく共有ファイル共有から同時に読み込めるため、コンテナイメージの肥大化や重複コピーを避けつつ、小規模から中規模モデルでは新規レプリカを数秒で立ち上げられるとしている。Linux NFSのnconnectマウントオプションにも対応する。
- AIやデータ集約型ワークロード向けには、新しいZonal placementでGPU仮想マシンと同じ可用性ゾーンにファイル共有を配置でき、provisioned v2 billing modelでIOPSとスループットを独立して設定できる。
- クラウドネイティブ領域では、Azure Files CSI driverを通じてAKSと統合し、StorageClassesによる動的プロビジョニング、拡張可能な永続ボリューム、ReadWriteManyの共有アクセスを提供する。さらに新しいfile share experienceは、1サブスクリプション・1リージョン当たり最大10,000共有と約2.5倍高速なプロビジョニングをうたう。
- 既存のLinux/NFS業務アプリ移行向けには、Azure Storage MoverとAzure Migrate support for NFSで評価・計画・移行を支援し、運用開始後はsnapshots、soft delete、NFSのencryption in transitで復旧性と保護を強化できるとしている。
- パートナーやISV向けには、独自APIではなくSMB 3.xとNFS 4.1の標準プロトコルを前面に出し、NFS Snapshot、Soft Delete、NFS shares向けREST APIを通じてBCDR、データ移動、管理、アプリ連携を組み込みやすくした。

<details><summary>English summary</summary>

Azure Files expanded its support for modern Linux workloads with new NFS-focused capabilities. For AI inference, new zonal placement and the provisioned v2 billing model enable same-zone placement with GPU VMs and independent tuning of IOPS and throughput. For AKS and migrations, Microsoft also highlights CSI integration, a new file share experience with up to 10,000 shares per subscription per region and about 2.5x faster provisioning, plus Azure Storage Mover and Azure Migrate support for NFS.

</details>

**重要ポイント**
- Microsoftは2026年版Gartner Magic Quadrant for Analytics and Business Intelligence PlatformsでLeaderに選ばれたと発表しており、本文では19年連続としている。Gartnerレポートの表記日は2026年6月29日。
- Power BIは単独のBI製品ではなくMicrosoft Fabricの中核として位置付けられ、共有データ基盤による一貫したガバナンス、セキュリティ、管理と、単一Fabric容量による統一料金モデルを訴求している。
- Power BIのセマンティックモデルは利用数が2,000万超とされ、オープン形式のためM365サービス、カスタムアプリ、サードパーティーアプリから再利用できる。記事は、これがAIやエージェントが生データではなく信頼できる指標に基づいて推論する土台になると説明している。
- Microsoft 365 CopilotおよびMicrosoft 365 Copilot Chatとの連携により、利用者はPower BIの業務データについて質問したり、Copilotから直接Power BIデータを照会したりできるとされる。回答は信頼できる業務定義に基づく形で提供される。

Microsoft says Power BI and Microsoft Fabric were recognized as a Leader in the 2026 Gartner Magic Quadrant for Analytics and Business Intelligence Platforms. The post attributes this to Fabric’s unified analytics foundation centered on Power BI, its single-capacity unified pricing model, more than 20 million semantic models, and Copilot integrations. It also highlights that Power BI data can be queried directly from Microsoft 365 Copilot Chat and describes this as Microsoft’s nineteenth consecutive year in the Leader position.
