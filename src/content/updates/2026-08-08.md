### Azure Blog (1)

#### [Microsoft named a Leader in the 2026 Gartner® Magic Quadrant™ for AI-Augmented Code Modernization Tools](https://azure.microsoft.com/en-us/blog/microsoft-named-a-leader-in-the-2026-gartner-magic-quadrant-for-ai-augmented-code-modernization-tools/)
- 公開日時: 2026-08-06T15:00:00.000Z
- 要約: GitHub Copilot modernizationとModernize CLIを中心とするMicrosoftのAI活用モダナイゼーション製品群が、初版の2026 Gartner Magic Quadrant for AI-Augmented Code Modernization ToolsでLeaderに位置付けられた。記事では、Azure移行に向けた評価・計画・フレームワーク更新を横断して自動化しつつ、IDE内で開発者が計画を実行できるエンドツーエンド方式を訴求している。対応範囲は.NET、Java、C++、Pythonに及び、Microsoftによると移行時間を最大70%削減し、アプリ更新の工数を50%減らした事例がある。
- なぜ重要か: 書き換えも放置も難しいレガシー資産を抱える企業のアーキテクト、アプリ所有者、開発者に関係する発表だ。記事は、複数アプリをまとめて評価・計画し、更新後のビルド検証やテスト移行、CVEスキャンまでをワークフローに組み込める点を強調しており、個別案件ごとの手作業に偏りがちなモダナイゼーションを、再利用可能で統制しやすい運用に変えたい組織に影響する。

**重要ポイント**
- Microsoftは、AIによるコードモダナイゼーション製品に関する初版の2026年Gartner Magic QuadrantでLeaderに選ばれたと述べている。記事内で参照されるレポートの日付は2026年8月3日。
- 中核となるGitHub Copilot modernizationは、アプリケーションの評価、更新、Azure移行を支援するエージェント型のエンドツーエンド手法として説明されている。Modernize CLI経由のmodernization agentが複数アプリの評価・計画・フレームワーク更新自動化を担い、開発者はIDE内のGitHub Copilotでその計画を実行する。
- 対象言語は.NET、Java、C++、Pythonで、managed identities、Azure Key Vault、Blob and File storage、Microsoft Entra IDへの移行パターンを定義済みタスクとして扱う。さらにcustom skillsで社内の実績ある変更パターンを再利用できるとしている。
- 効果についてMicrosoftは、利用顧客が移行作業時間を最大70%削減し、アプリ更新の工数を50%削減したと報告していると主張する。数週間で50万行超のコードを移行した例や、導入数が140万人超という数字も示している。

<details><summary>English summary</summary>

Microsoft says its GitHub Copilot modernization offering, including the Modernize CLI, was positioned as a Leader in the inaugural 2026 Gartner Magic Quadrant for AI-Augmented Code Modernization Tools. The article describes an end-to-end workflow for assessing, upgrading, and migrating applications to Azure while keeping developers in control inside the IDE. It spans .NET, Java, C++, and Python, and Microsoft claims customers have seen up to 70% less migration time and 50% less upgrade effort.
