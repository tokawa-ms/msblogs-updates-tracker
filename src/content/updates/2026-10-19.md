### Azure Blog (1)

#### [Evolving the cloud-native foundation for the next generation of AI](https://azure.microsoft.com/en-us/blog/evolving-the-cloud-native-foundation-for-the-next-generation-of-ai/)
- 公開日時: 2026-10-15T16:00:00.000Z
- 要約: Azureは、AIアプリケーションとエージェント向けにクラウドネイティブ基盤を進化させ、計算・ストレージ・ネットワークを一体で最適化する方針を示した。併せて、Azure Kubernetes Serviceでオープンソース技術を本番利用しやすくし、モデル費用と基盤費用を合わせて見るFinOps的な管理や、AIを使った運用自動化の拡大を打ち出している。記事では、こうした取り組みをAzure上でAIを大規模運用するための基盤整備として位置付けている。
- なぜ重要か: AIアプリやエージェントを本番展開する企業の開発・運用・財務チームに関係する内容だ。記事は、需要変化に追随する基盤、オープンソース統合に必要な専門性、モデル利用と周辺インフラを含む総コストをまとめて扱う必要があるとし、既存のクラウドネイティブ基盤を作り直すのではなく進化させる方向を示している。

**重要ポイント**
- AI基盤では単に容量を増やすのではなく、処理段階ごとに加速計算、CPU、データアクセス、接続性など必要資源を切り替え、適切な資源を適切なタイミングで割り当てるべきだとAzureは説明している。事例としてBasecamp ResearchはAzureを使ってEDEN向けに9.7兆塩基をアセンブルし、約3週間で3つの治療用途に関する実験室検証を報告した。
- オープンソース活用では、2028年までに新規AIエージェント導入の95%がKubernetesを使うというGartner予測を示しつつ、AKSが本番運用の複雑さやリスクを抑えながら選択肢を確保する手段として位置付けられている。
- コスト面では、モデル料金だけでなく、トークン使用量、エージェントの挙動、計算・ストレージ・ネットワーク・運用まで含めて総額を把握し、FinOpsで投資対効果を判断しながらガードレールを整える必要があるとしている。
- 運用では、エージェント型AIが分断されたシステムのシグナルをつなぎ、問題の早期発見と迅速な解決、自動化の拡大を支援するという。より多くの処理を自動化しても、人は重要な意思決定で関与し続ける前提が示されている。
- 記事末尾では、最近のAzureの関連技術としてFlex Nodes for AKS、Azure SRE Agent、Azure Container Apps Sandboxes、Azure Container Apps Expressを挙げ、AIアプリケーションとエージェント向け基盤の具体例として案内している。

<details><summary>English summary</summary>

Azure says it is evolving its cloud-native foundation for AI applications and agents, with compute, storage, and networking optimized together. It also positions Azure Kubernetes Service as a way to use open-source technologies in production more easily, while promoting FinOps-style management across model and platform costs and broader AI-driven operations automation. The article frames these efforts as the foundation for running AI at scale on Azure.

**Why it matters:** This matters to development, operations, and finance teams at organizations putting AI applications and agents into production. The article argues that they need infrastructure that can adapt to changing demand, a way to manage the expertise required for open-source integration, and a full view of costs across models and surrounding infrastructure, while evolving existing cloud-native foundations rather than rebuilding them from scratch.

**Key points**
- For AI infrastructure, Azure argues that organizations should not just add more capacity but match accelerated compute, CPUs, data access, and connectivity to each stage of work at the right time. As an example, Basecamp Research used Azure to assemble 9.7 trillion nucleotides for EDEN and reported laboratory validation across three therapeutic applications in about three weeks.
- On open-source adoption, the article cites Gartner’s forecast that 95% of new AI agent deployments will use Kubernetes by 2028, and presents AKS as a way to preserve choice while reducing production complexity and risk.
- On costs, it says teams need to look beyond model pricing to total spend across token usage, agent behavior, compute, storage, networking, and operations, using FinOps and guardrails to assess return on investment.
- For operations, it says agentic AI can connect signals across disconnected systems to help teams detect issues earlier, resolve them faster, and automate more work, while keeping humans accountable for critical decisions.
- At the end, the article points to Flex Nodes for AKS, Azure SRE Agent, Azure Container Apps Sandboxes, and Azure Container Apps Express as recent Azure innovations relevant to this AI foundation.

</details>

### Microsoft 365 Blog (1)

#### [Announcing the new Work IQ APIs](https://www.microsoft.com/en-us/copilot/blog/2026/06/02/announcing-the-new-work-iq-apis/)
- 公開日時: 2026-06-02T17:00:15.000Z
- 要約: MicrosoftはWork IQ APIsを2026年6月16日に一般提供すると発表し、それに先立ちGitHubでパブリックプレビューを公開している。これはMicrosoft 365のデータやアプリをエージェントから扱うためのAPI群で、Chat、Context、Tools、Workspacesの4領域を通じてCopilot相当の応答、業務コンテキスト取得、操作実行、中間状態の保存を提供する。価格はCopilot Credits建ての従量課金で、Toolsは固定要素、ChatとContextは変動要素になる。
- なぜ重要か: Microsoft 365内で業務エージェントを構築する開発者と、利用統制を担うIT管理者に影響が大きい。開発者はCopilot相当の応答や業務コンテキスト、操作APIを同じ基盤で利用でき、IT管理者はテナント境界内で監査可能な実行とクレジット管理ダッシュボードによって、追加の統制レイヤーなしでガバナンスとコスト管理を進めやすくなる。

**重要ポイント**
- 一般提供は2026年6月16日で、現時点ではGitHub上のパブリックプレビューから先行して利用を始められる。
- APIはChat、Context、Tools、Workspacesの4ドメインで構成され、Copilotの応答取得、エージェント向けコンテキスト取得、Microsoft 365上の操作実行、実行中の中間状態やデータの保管を分担する。
- ToolsはMCPによる段階的開示を備えた10個の汎用ツールに操作を集約しており、メール送信、会議設定、文書アップロードなどを、データごとの多数のツールを教え込まずに扱えるようにする。
- 料金はCopilot Creditsによる従量課金で、Toolsは固定要素、ChatとContextは変動要素になる。あわせてMicrosoft 365管理センターに新しいコスト管理ダッシュボードが導入され、AIクレジット利用確認、前払いまたは従量課金の設定、テナント・グループ・ユーザー単位の上限設定などを行える。

<details><summary>English summary</summary>

Microsoft announced that Work IQ APIs will become generally available on June 16, 2026, and has already opened a public preview on GitHub. The API set is meant for agents to work with Microsoft 365 data and apps, spanning four areas—Chat, Context, Tools, and Workspaces—for Copilot-like responses, business context retrieval, action execution, and intermediate state storage. Pricing is usage-based in Copilot Credits, with a fixed component for Tools and variable components for Chat and Context.

**Why it matters:** This matters most to developers building enterprise agents inside Microsoft 365 and to IT administrators responsible for governance. Developers get a single foundation for Copilot-like responses, business context, and action APIs, while IT admins get auditable execution inside the tenant boundary and a credit management dashboard that helps them manage governance and costs without adding a separate control layer.

**Key points**
- General availability is set for June 16, 2026, and developers can start earlier through the public preview on GitHub.
- The APIs are organized into four domains—Chat, Context, Tools, and Workspaces—covering Copilot response access, agent-ready context retrieval, Microsoft 365 actions, and storage for intermediate execution state and data.
- Tools condense operations into 10 generic tools with progressive disclosure through MCP, enabling actions such as sending emails, scheduling meetings, and uploading documents without teaching agents hundreds of data-specific tools.
- Pricing is usage-based in Copilot Credits, with a fixed component for Tools and variable components for Chat and Context. Microsoft is also introducing a new cost management dashboard in the Microsoft 365 admin center for reviewing AI credit usage, choosing prepaid or pay-as-you-go billing, and setting spending limits by tenant, group, and user.

</details>
